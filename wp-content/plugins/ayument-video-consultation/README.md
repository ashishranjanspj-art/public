# AyuMent Video Consultation
WordPress/WebRTC doctor-patient video call MVP.

Upload and activate the ZIP. The call UI is available through `/?ayu_video=1&room=ROOM_CODE`.
The next integration step is to connect the existing AyuMent appointment/consultation records to the Create Call endpoint so the doctor sees Start Video Call and the patient sees Join Video Call.

Production deployment should use HTTPS and a TURN server for reliable connections across restrictive networks.
